# LendLoop n8n automation

Three workflows (source of truth: `n8n/workflows/*.json`, generated by `scripts/build-workflows.mjs`):

| Workflow | Id | What it does |
| --- | --- | --- |
| Request notification | `llRequestNotify1` | `POST /webhook/lendloop/request-notification`. Verifies `X-LendLoop-Signature` (`t=<unix>,v1=HMAC-SHA256(secret, "<t>.<raw body>")`, 300 s window, constant-time compare) over the raw body, de-duplicates by `eventId` (workflow static data, last 500), answers 401 on failure, logs a mock notification (masked address), then reports to Convex `/n8n/notification-status`. |
| Overdue reminders | `llOverdueRemind1` | Daily 09:00 (plus a manual trigger). Signed `GET /n8n/overdue-loans`, mock reminder per loan, signed `POST /n8n/reminder-status` with key `reminder:<loanId>:<UTC date>`. |
| Error handler | `llErrorHandler01` | Error Trigger for both workflows (`settings.errorWorkflow`). Logs a structured error and posts `/n8n/automation-failure` (`fail:<executionId>`). |

All HTTP nodes retry 3 times (2 s apart). Secrets are never in the workflow JSON and Code nodes cannot read env (`N8N_BLOCK_ENV_ACCESS_IN_NODE=true`). They live in two n8n credentials of type `lendLoopHmacApi`, which a small local node (`custom/n8n-nodes-lendloop`, plain JS, loaded via `N8N_CUSTOM_EXTENSIONS=/custom`) uses to sign (Sign), verify (Verify) and call the replay-protected overdue GET with a fresh signature per attempt (Signed Request). The scheme matches `convex/lib/hmac.ts`. The node's source: `LendLoopHmac.node.js`; keep it in sync with that file.

Credentials (fixed ids `llCredWebhook01` Convex to n8n, `llCredInbound01` n8n to Convex plus the Convex base URL) are created by `entrypoint.sh` on every start: it builds a temp JSON from the env vars, runs `n8n import:credentials` (idempotent by id, encrypted with `N8N_ENCRYPTION_KEY`) and deletes the file. Workflow JSON references them by id and name only. Rotating a secret: edit `n8n/.env`, then `docker compose up -d --force-recreate`.

## Run

```bash
cp n8n/example.env n8n/.env          # then fill in secrets: openssl rand -hex 32
cd n8n && docker compose up -d       # imports + publishes workflows on every start
```

The entrypoint (`entrypoint.sh`) imports the credentials, then runs `n8n import:workflow --separate`, then `n8n publish:workflow --id=...` for each workflow (import deactivates them; `--activeState=fromJson` only works in queue mode), then starts n8n at http://localhost:5678.

Set the matching values on the Convex deployment:

```bash
npx convex env set LENDLOOP_WEBHOOK_SECRET <same as n8n/.env>
npx convex env set N8N_INBOUND_SECRET <same as n8n/.env>
npx convex env set N8N_WEBHOOK_URL http://localhost:5678/webhook/lendloop/request-notification
```

`CONVEX_SITE_URL` (n8n/.env) must be reachable from the container: `http://host.docker.internal:3211` for the local backend (the compose file maps `host.docker.internal` to the host gateway).

## Env vars (n8n/.env)

`LENDLOOP_WEBHOOK_SECRET` (Convex -> n8n), `N8N_INBOUND_SECRET` (n8n -> Convex), `CONVEX_SITE_URL`, `N8N_ENCRYPTION_KEY`, `GENERIC_TIMEZONE`, optional `N8N_DOCKER_SUBNET` (default `172.28.200.0/24`; pinned so it does not collide with VPN routes). The compose file also sets `N8N_BLOCK_ENV_ACCESS_IN_NODE=true`, `N8N_CUSTOM_EXTENSIONS=/custom` and `CODE_ENABLE_STDOUT=true` (Code node logs appear in `docker compose logs`). The env vars are consumed only by `entrypoint.sh`; the container env still holds them (visible to `docker inspect`), but workflow code cannot read them.

## Smoke test

Needs Convex running with `ALLOW_DEV_SEED=true` (`npx convex env set ALLOW_DEV_SEED true`) and n8n up:

```bash
node scripts/smoke-n8n.mjs
```

It seeds data through `convex/devSeed.ts`, then checks the delivery round trip, signature/replay rejection, dedupe, overdue idempotency and the error handler. `node scripts/sign-request.mjs LENDLOOP_WEBHOOK_SECRET '<body>'` prints a signature header for manual `curl` tests.

## Notes

- `n8n execute` inside the running container needs `-e N8N_RUNNERS_BROKER_PORT=5680` (port 5679 is taken by the server).
- Never re-export workflows from a live instance into this folder without scrubbing; edit `scripts/build-workflows.mjs` and regenerate.
- GET retries reuse the signed request; if Convex already processed it, the retry returns 409 (replay protection) and the error handler records it.
